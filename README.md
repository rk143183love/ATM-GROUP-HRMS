# ATM GROUP Attendance App

A responsive attendance-management MVP for Saideep and Pinnacle.

## Current MVP
- Company selection
- Date-based attendance
- Present / Absent / Unmarked status
- Add and deactivate employees
- Dashboard statistics
- CSV export
- Browser localStorage persistence

## Next production step
Connect the UI to Google Apps Script and Google Sheets, then add authenticated CEO/MD/Supervisor roles, supervisor company-level access, monthly spreadsheets, employee master, audit logging, and server-side validation.

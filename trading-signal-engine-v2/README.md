# Trading Signal Engine V2

Rule-based BUY / SELL / NO TRADE research prototype.

## V2 focus
- Multi-timeframe trend confirmation
- Market structure and breakout confirmation
- Liquidity-style sweep and rejection
- RSI + MACD momentum confirmation
- Relative volume filter
- ATR volatility filter
- Overextension filter
- Session filter
- 100-point signal scoring
- Locked ATR-based SL/TP
- Alerts and dashboard

The score is a confidence score for rule alignment, not a probability of winning. This project is for backtesting/paper testing and does not guarantee accuracy or profit.

Initial research target: XAUUSD 5-minute.
